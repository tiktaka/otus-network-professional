## Цель
В данной самостоятельной работе необходимо распланировать адресное пространство.\
Настроить IP на всех активных портах для дальнейшей работы над проектом.\
Адресное пространство должно быть задокументировано.

## Задание
1. Разработаете и задокументируете адресное пространство для лабораторного стенда;
2. Настроите IP адреса на каждом активном порту;
3. Настроите каждый VPC в каждом офисе в своем VLAN;
4. Настроите VLAN/Loopback interface управления для сетевых устройств;
5. Настроите сети офисов так, чтобы не возникало broadcast штормов, а использование линков было максимально оптимизировано.

### Конфигурация устройств
#### Настройка IP адреса на каждом активном порту
Настраиваем IP адрес на интерфейсах и включаем их:
```
# Пример с роутера R19 в Москве
interface Ethernet0/0
 description Msk - R14 - e0/3
 ip address 10.0.0.21 255.255.255.252
 no shutdown
```
#### Настроика каждого VPC в каждом офисе в своем VLAN
1. На L3-коммутаторах создаём vlan, svi-интерфейс:
```
vlan 20
name Servers

interface vlan 20
 description VLAN 20 (Servers)
 ip address 10.20.0.1 255.255.255.0
 no shutdown
```
На роутерах сабинтерфейс:
```
# R28
interface Ethernet0/2.20
 description VLAN 20 (Servers)
 encapsulation dot1Q 20
 ip address 10.20.0.1 255.255.255.128
end
```
2. На access L2-коммутаторах создаём vlan и переводим необходимые порты в режим access с нужным vlan:
```
vlan 20
name Servers

interface ra ethernet 0/2
switchport mode access
switchport access vlan 20
```
3. Организуем транк между коммутаторами (или между коммутаторами и роутером):
```
# Spb_SW29
interface ethernet 0/2
switchport trunk encapsulation dot1q
switchport mode trunk
```
Между коммутаторами, где есть более одного линка, настраиваем etherchannel и транк:
```
interface ra ethernet 0/0-1
channel-protocol lacp
channel-group 1 mode passive

interface port-channel 1
switchport trunk encapsulation dot1q
switchport mode trunk
```

#### Настроить VLAN/Loopback interface управления для сетевых устройств
На всех коммутаторах и роутерах настроен vlan99, который предназначен для управления устройствами:
```
# Spb_SW29
vlan 99
name Management

interface vlan 99
 description VLAN 99 (Management)
 ip address 10.99.0.2 255.255.255.128
 no shutdown
```
```
# Chokudarh_R28
interface Ethernet0/2.99
 description VLAN 99 (Management)
 encapsulation dot1Q 99
 ip address 10.99.0.1 255.255.255.128
end
```

А также, везде настроен Loopback-интерфейс с маской 32 бита:
```
# Msk_R19
interface Loopback0
 description Loopback
 ip address 100.77.19.254 255.255.255.255
```

#### Настроите сети офисов так, чтобы не возникало broadcast штормов, а использование линков было максимально оптимизировано
Везде, между роутерами и l3-коммутаторами, используются линки точка-точка с маской 30 бит, чтобы ограничить широковещательный домен. А, также, настроены VLAN, тоже для разграничения трафика и разделения широковещательных доменов.\
На всех коммутаторах включен протокол RSTO по умолчанию, который позволяет избежать петель в сети.
